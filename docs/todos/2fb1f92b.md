## Context

The fastlane workflow was previously renamed from the hyphenated identifier `fast-lane` to the single-word form `fastlane`, but some live workflow documentation and prompts still use the spaced prose form `Fast Lane` / `fast lane`.

Adopt one consistent spelling:

- Use `fastlane` mid-sentence.
- Use `Fastlane` at the start of a sentence, heading, or title/phrase such as `Fastlane Coder Prompt`.
- Keep existing identifiers like `/fastlane`, `fastlane-coder`, and `-fastlane-review` as-is.

## Scope

Update live workflow docs/prompts only. Historical/provenance artifacts under `docs/plans/`, `docs/analysis/`, `docs/reviews/`, and completed `docs/todos/` may still contain old `fast-lane`, `Fast Lane`, or `fast lane` references and should be left alone unless separately requested.

## Known live occurrences to update

- `agent/skills/fastlane/fastlane-coder-prompt.md:1`
  - `# Fast Lane Coder Prompt` → `# Fastlane Coder Prompt`
- `README.md:102`
  - Mermaid label `f: fast lane` → `f: fastlane`
- `README.md:117`
  - Menu prose `(f) fast lane` → `(f) fastlane`
- `agent/skills/define-spec/SKILL.md`
  - Step 8 recommendation/menu/routing text currently uses `fast lane` in several places.
  - Update display/recommendation/routing prose to `fastlane` / `Fastlane` as appropriate, while keeping the slash command `/fastlane` unchanged.
- `agent/skills/fastlane/SKILL.md`
  - Headings, menu text, warnings, status text, provenance lines, and edge-case bullets use `Fast lane` / `fast lane` in several places.
  - Update them to `Fastlane` / `fastlane` as appropriate.
