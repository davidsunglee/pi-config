## Problem

`agent/skills/execute-plan/scripts/extract-plan-tasks.py` incorrectly treats heading-like lines inside fenced code blocks as real markdown structure. This can truncate task blocks and cause false validation failures.

## In scope

Harden the parser so that heading-like structure is ignored while inside fenced code blocks for these code paths:

- task start detection (`### Task N: ...`)
- task block end detection (`## ...`, `### Task N: ...`)
- required section validation/body scanning

## Fence behavior requirements

Support fenced code blocks with the following rules:

- recognize both backtick fences and tilde fences
- support fence lengths of 3 or more characters
- allow fences with leading indentation
- require closing fences to use the same marker type as the opener
- require closing fences to be at least as long as the opener
- if a fence is opened and never closed, treat the rest of the file as inside the fence for structure parsing purposes

## Explicitly out of scope

- broader markdown parser hardening beyond heading/task/section detection inside fenced code blocks
- removing the temporary workaround from `docs/plans/2026-05-08-2026-05-08-define-spec-and-artifact-handoff-fixes.md`

## Regression coverage

Add both:

1. a minimal synthetic parser fixture
2. a realistic regression fixture close to the actual failure pattern

Tests should explicitly cover fenced content containing both:

- fake section headings like `## Completion contract`
- fake task headings like `### Task 999: Not a real task`

Assertions should verify that:

- fenced headings do not create tasks
- fenced headings do not truncate the surrounding real task block
- content after the fence remains part of the task
- `**Model recommendation:** standard` after the fence is still parsed correctly
- required section validation ignores heading-like lines inside fences

## Acceptance criteria

- relevant parser / unit tests are added or updated
- parser / unit tests pass

## Context

This issue was observed in `docs/plans/2026-05-08-2026-05-08-define-spec-and-artifact-handoff-fixes.md`, where fenced markdown content included heading-like lines that were misinterpreted as real structure.
