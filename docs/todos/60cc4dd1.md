## Goal

Rename the fast-lane skill and its literal references to the one-word form `fastlane`.

## Context

The current skill uses the hyphenated name `fast-lane` in its skill folder, frontmatter, prompt filenames, paths, review artifact suffixes, subagent/task names, and user-facing messages. We want a literal rename to `fastlane`, including paths and filenames, not just prose.

## Desired scope

- Rename the skill folder from `agent/skills/fast-lane/` to `agent/skills/fastlane/`.
- Rename files containing `fast-lane`, including `fast-lane-coder-prompt.md` to `fastlane-coder-prompt.md`.
- In the renamed `agent/skills/fastlane/SKILL.md`, replace every literal `fast-lane` with `fastlane`, including:
  - frontmatter skill name,
  - helper/template paths,
  - subagent/task names,
  - review artifact suffixes,
  - user-facing error prefixes,
  - stash/test-run artifact naming.
- Update repository references outside the skill definition so renamed paths continue to work, including README references, tests, docs, scripts, and workflow docs that mention `agent/skills/fast-lane` or `/fast-lane`.
- Confirm renamed skill references point to real files.

## Acceptance criteria

- `agent/skills/fastlane/SKILL.md` exists and contains no literal `fast-lane` occurrences.
- `agent/skills/fast-lane/` no longer exists unless a deliberate compatibility shim is documented.
- `agent/skills/fastlane/fastlane-coder-prompt.md` exists and all SKILL.md template references point to it.
- Repository references to the old `agent/skills/fast-lane` path are updated or explicitly documented as compatibility notes.
- Relevant fastlane helper tests pass.
